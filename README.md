# Geometry with C++
Мой личный проект для практики написания программного обеспечения на C++ и изучение геометрических алгоритмов и способность довести библиотеку обработки геометрии до проверяемого результата. Сейчас он состоит из библиотеки для работы с двумерными векторами и консольного примера.

## Что уже есть
Сложение, вычитание, скалярное произведение двух векторов, вычисление длины вектора и угла между векторами; программа сообщает, что угол не определён, если один из векторов нулевой; умножение вектора на коэффициент.

## Сборка и запуск на Windows
Для сборки нужны Visual Studio с инструментами C++ и CMake
Открой Developer PowerShell для Visual Studio 2022 и перейди в корень
репозитория Kumometry — туда, где находится `CMakeLists.txt`.

Выполни команды по порядку:

```powershell
cmake -S . -B out/build/clean-check
cmake --build out/build/clean-check --config Debug
.\out\build\clean-check\Debug\MyApp.exe
```

Первая команда настраивает сборку, вторая собирает библиотеку и приложение,
третья запускает консольный пример.

## Запуск тестов
```powershell
ctest --test-dir out/build/clean-check -C Debug --output-on-failure
```
## Ограничения 
Консольный ввод, вычисления с погрешностью double.
