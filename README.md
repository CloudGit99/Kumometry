# Geometry witch C++
Мой личный проект для практики написания программного обеспечения на C++ и изучение геометрических алгоритмов и способность довести библиотеку обработки геометрии до проверяемого результата. 

## Что уже есть
Сложение, скалярное произведение, длины и угол; обработка нулевого вектора.

## Как запустить
Открыть .sln в Visual Studio, выбрать C++20, собрать и запустить.

## Ограничения 
Консольный ввод, вычисления с погрешностью double, автоматических тестов пока нет.
